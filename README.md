# WL Design — Autoridades Digitais

Landing page profissional para o estúdio de desenvolvimento web WL Design.

## 🚀 Stack

- **HTML5** semântico e acessível
- **Tailwind CSS** (via CDN) com configuração customizada
- **JavaScript** vanilla — sem dependências externas pesadas
- Google Fonts: `Inter` + `Syne`

## 📁 Estrutura

```
WL DESIGN/
└── index.html        ← Arquivo único — pronto para GitHub Pages
```

## 🌐 Deploy no GitHub Pages

1. Crie um repositório no GitHub (ex: `wl-design`)
2. Faça o push de `index.html` para a branch `main`
3. Vá em **Settings → Pages → Source → Deploy from branch → main / root**
4. Acesse `https://seuusuario.github.io/wl-design/`

## ✨ Funcionalidades

- **Dark Mode luxuoso** com acentos em índigo/violeta
- **Scroll Reveal** — elementos surgindo suavemente
- **Cursor glow** — luz suave seguindo o mouse (desktop)
- **Contadores animados** — números que crescem ao entrar na tela
- **Card shine** — brilho que segue o cursor nos cards de projeto
- **Tilt effect** — leve inclinação 3D nos cards de diferenciais
- **Parallax** nos orbs do Hero
- **Botão pulsante** no CTA principal
- **Botão flutuante do WhatsApp**
- **Nav blur** ao rolar a página
- **Mobile menu** responsivo
